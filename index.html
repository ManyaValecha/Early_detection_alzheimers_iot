Rigorous Science

🔬 Research Methodology

Zero-leakage participant splits, bootstrap confidence intervals, clinically validated evaluation standards.

🛡️

Zero Participant Leakage

GroupShuffleSplit along patient_id. Train ∩ Val ∩ Test = ∅. Formally verified with set intersection test.

len(set(Train) ∩ set(Test)) == 0
🎯

Validation-First Selection

All algorithm tuning on validation split only. Final AUC from a single evaluation of held-out test — never re-tuned on test data.

📉

Bootstrap 95% CIs

1,000 bootstrap resamples of held-out test set. Statistically robust confidence intervals for all AUC figures.

📊

PR-AUC + ROC-AUC

Both metrics for Model 2. Class imbalance (~6-8% positive days) means ROC-AUC can mislead — PR-AUC gives honest view.

📡

TIHM Cohort (Palermo 2023)

Open dataset — Nature Scientific Data. 56 participants, ~2,800 days. PIR motion, sleep, physiology, clinician-logged adverse events.

DOI: 10.5281/zenodo.7622128
🧮

Geometric Mean Combination

AUC_combined = √(AUC₁ × AUC₂). Balances both models equally without letting either dominate.

√(0.990 × 0.843) = 0.9136

Dataset Split Protocol

Training — 70%
Val 15%
Test 15%
Train: Algorithm fitting only
Validation: Model selection (no test peeking)
Test: Final reporting — evaluated once only

📚 Data Citations

TIHM Dataset: Palermo, F. et al. (2023). A multivariate time series dataset for evaluating machine learning methods in smart home monitoring for people with dementia. Nature Scientific Data, 10, 606.

OASIS: Marcus, D.S. et al. Open Access Series of Imaging Studies. Journal of Cognitive Neuroscience, 2007.

ADNI: Jack, C.R. et al. Alzheimer's Disease Neuroimaging Initiative. Neurology, 2008.
