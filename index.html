Model 2: TIHM Longitudinal Health-Event Detection

Continuous in-home telemonitoring of 56 participants across 2,800+ participant-days. TIHM cohort (Palermo et al., Nature Scientific Data 2023).

TIHM IoT Sensor Streams

🚶
PIR Motion

5 zones: Hallway, Kitchen, Bathroom, Living, Bedroom. Hourly activity counts + baseline z-scores.

🌙
Nocturnal Transitions

Night-time room transitions count. Surge detection vs. 7-day rolling baseline.

🛏️
Sleep Mattress

Restlessness events per night. Bed exit count. Sleep efficiency % from mattress sensor.

💓
Vitals (Physiology)

Blood pressure (systolic/diastolic), pulse rate. Daily measurements at fixed times.

🎯
Target Events

Clinician-confirmed: UTIs, agitation episodes, fall risks. 24-48h advance warning window.

📈
Rolling Z-Scores

All sensor readings normalized against 7-day rolling individual baseline for anomaly detection.

🔬 Methodology

Research Methodology & Validation Protocol

Rigorous zero-leakage participant splits, bootstrap confidence intervals, and clinically validated evaluation standards.

🛡️

Zero Participant Leakage

GroupShuffleSplit partitioned strictly along patient_id. Formal verification: TrainIDs ∩ ValIDs ∩ TestIDs = ∅. No participant data exists in multiple splits.

len(set(Train) ∩ set(Val) ∩ set(Test)) == 0
🎯

Validation-First Selection

All algorithm tuning and selection conducted exclusively on the validation split. Final performance reported on a single evaluation of the held-out test split — never re-tuned on test data.

📉

Bootstrap 95% CIs

1,000 bootstrap resamples of the held-out test set. Provides statistically robust confidence intervals for all AUC figures. Prevents cherry-picking of favorable runs.

📊

PR-AUC + ROC-AUC

Both metrics reported for Model 2 (IoT). Class imbalance (~6-8% positive days) means ROC-AUC can be misleading. PR-AUC provides honest view of precision-recall trade-off.

📡

TIHM Cohort (Palermo 2023)

Open dataset from Nature Scientific Data. 56 participants, ~2,800 participant-days. PIR motion, sleep, physiology, clinician-logged adverse event labels. DOI: 10.5281/zenodo.7622128

🧮

Geometric Mean Combination

Combined AUC = √(AUC₁ × AUC₂). Geometric mean is appropriate for combining ratios/rates — it balances both models equally without letting one dominate.

√(0.990 × 0.843) = 0.9136
