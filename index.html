🎙️ Speech Assessment

Clinical speech analysis — the model extracts pause ratio, lexical diversity, speaking rate, and pitch variability in real time.

Assessment Protocol

3 Tasks
1

Cookie Theft Description

Describe what you see in the Cookie Theft picture for 60 seconds. The system analyses lexical diversity, semantic density, and syntactic complexity.

2

Verbal Fluency — Animals

Name as many animals as possible in 60 seconds. Tests semantic memory retrieval speed and category clustering.

3

Read-aloud Passage

Read the displayed passage aloud. Analyses speaking rate (WPS), pause duration ratio, jitter, and shimmer.

Read aloud: "The old man sat quietly by the window, watching the birds outside. He tried to remember their names, but the words felt distant — like stones sinking in deep water."
