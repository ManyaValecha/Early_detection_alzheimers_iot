How our system works from home sensors to behavioural insight — the four-stage pipeline

1

Sensor & behavioural data

What goes in

Passive data from in-home sensors in the TIHM study — motion sensors, door sensors and other environmental sensors.

What it tells us
  • When a person moves around the home
  • How often they enter or leave rooms
  • Changes in usual daily activity
  • Shifts in routine, where sensors support it
2

Processing & personal baseline

What happens
  • Remove invalid / duplicate records
  • Order sensor events by date & time
  • Compute daily activity, room visits & duration
  • Learn what is normal for that person
Example: if someone usually enters the kitchen around 8 AM, that repeated pattern defines their normal routine.
3

Behavioural deviation analysis

What happens
  • Detect unusually low or high activity
  • Identify changes in room-use patterns
  • Observe routine drift over time
  • Compare deviations with recorded clinical events, where labels exist
Example: regular morning activity that drops to almost nothing for several days is flagged for review.
4

Interactive dashboard

What the user sees
  • Activity chart — activity levels across days
  • Daily routine — sensor activity by hour
  • Room-use — activity by area
  • Deviation alerts — days off the personal baseline
  • Event comparison — deviations vs recorded events
What a flag means: an unusual pattern is a signal for investigation, not proof of Alzheimer's disease or any specific medical condition. The goal is to help researchers — and, in a future clinically validated system, healthcare professionals — understand behavioural change over time, minimising reliance on any single abnormal observation.

Model comparison

Benchmarked against the published TIHM baselines

Honest framing for the panel: this is a preliminary baseline, not a finished result — full evaluation against clinical event labels is still in progress. TIHM contains only people living with dementia, so there is no healthy control group and this is not a dementia-vs-healthy classifier. The task is within-cohort behavioural-deviation detection (agitation) and per-person anomaly scoring, which is what the data genuinely supports. Agitation occurs on only ~4% of days, so a low precision/AUPRC is expected and consistent with the published literature; we report it transparently rather than inflating accuracy. An elevated score is a signal for investigation, not proof of Alzheimer's disease.
